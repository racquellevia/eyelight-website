# Bauhaus 1

Archived aesthetic: cream background, red/yellow/blue flat squares with 45° long black shadows.

## Restore

1. Set `ACTIVE_THEME` to `"bauhaus-1"` in `src/lib/theme.ts`.
2. In `SitePage.tsx`, import from `@/themes/bauhaus-1/BauhausShapes`.
3. Ensure `globals.css` imports `./themes/bauhaus-1/theme.css`.

Components: `BauhausShapes.tsx`, `theme.css`.
