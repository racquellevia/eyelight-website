# Bauhaus 3

Active aesthetic: classic Bauhaus poster — 3×4 modular grid (dice dots, semicircles, color bars), cream paper with subtle grain, primary red/blue/yellow palette, wide-tracked heavy type.

## Switch themes

Set `ACTIVE_THEME` in `src/lib/theme.ts` to `"bauhaus-1"`, `"bauhaus-2"`, or `"bauhaus-3"`.
