# Bauhaus 2

Active aesthetic: flat geometric mosaic — circles, arcs, and semicircles in a tight 4×3 grid. No shadows or strokes.

Palette: cream, navy, terracotta, mustard, forest green, dusty blue, salmon.

## Switch themes

Set `ACTIVE_THEME` in `src/lib/theme.ts` to `"bauhaus-1"` or `"bauhaus-2"`.
