# Miro 1

Constellations-inspired aesthetic for the Eyelight Labs one-pager: warm cream ground with soft color washes, thin black ink lines, biomorphic shapes, stars, eyes, and scattered dots.

## Palette

| Token   | Value     | Use                          |
|---------|-----------|------------------------------|
| paper   | `#f5f0e6` | Warm cream background        |
| ink     | `#1a1a1a` | Lines, type, blobs           |
| red     | `#c42b2b` | Dots, triangles, accents     |
| blue    | `#2b5faa` | Stars, crescents               |
| yellow  | `#d4a82a` | Eye highlights               |
| sky     | `#b8d4e8` | Background wash              |
| rose    | `#e8b4b0` | Background wash              |
| peach   | `#f0c9a0` | Background wash              |

## Components

- `MiroConstellationArt` — interactive hero SVG (hover each motif)
- `MiroAccent` — pillar / section markers (star, dot, crescent)

## Typography

Headlines use **Fraunces** (`--font-display`); body stays DM Sans.
