# First draft (archived)

This folder contains the **v1 Eyelight Labs portfolio site** — multi-page Next.js app with D3 visualization projects, scrollytelling (Midnight Census), and retro / Moroccan design iterations.

Archived when rebuilding as a Bauhaus minimal one-pager.

## What was here

- Home, Projects, About, Contact pages
- Seeded viz: Urban Breath, River Currents, Heritage Signal, Midnight Census
- Full `src/` and `public/` from that build

## Run the old site (optional)

Copy this folder’s `src` and `public` back to the repo root, restore `package.json` dependencies (including `d3`), then `npm install && npm run dev`.

Do not mix with the v2 one-pager without resolving conflicts.
